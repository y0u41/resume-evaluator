# 简历参谋 PRD

## 核心功能

### 用户功能
- 注册：邮箱、密码（≥6 位）
- 登录：返回 JWT（httpOnly Cookie），有效期 7 天；管理员用用户名登录
- 游客试用：免登录按 IP 试用 3 次，报告打码预览，不落库
- 个人中心：查看账号（用户名 / 邮箱 / 角色）、当日额度用量、套餐与到期日
- 账号注销：7 天冷静期、可撤销，到期物理删除账号与全部数据
- 数据隔离：所有记录按 `user_id` 隔离，互不可见

### 评估功能
- 发布评估：简历全文 + 应聘岗位（必填）、岗位 JD（选填），流式输出
- 评估报告：固定 9 节 —— 总分（十分制）、一句话结论、岗位匹配对照、三大优点、问题清单、逐条改法、AI 修改建议、关键词补齐、可继续增强的方向
- 岗位匹配对照：逐条列出 JD 要求，✅ / ⚠️ / ❌ 标注 + 匹配度进度条
- 客观评分（算法）：确定性引擎输出可复现的匹配度与四维评分（完整性 / 关键词覆盖 / 格式规范 / 量化成果），与 AI 报告并存、相互印证
- ATS 可解析性检测：姓名首行、联系方式、邮箱、板块标题、日期格式、要点符号
- 应届生模式：不因缺少工作经历扣分，重点看项目 / 实习 / 竞赛 / 潜力
- 继续追问：基于简历 + JD + 此前报告反复打磨具体段落（重写自我评价、项目改 STAR 等）
- 修改重评：评估后直接改简历 / 岗位 / JD 并重新评估；保存冲突返回 409 提示刷新，避免覆盖
- 录入方式：粘贴文本；上传 PDF / DOCX / DOC / TXT / MD（≤10MB）；图片与扫描版 OCR（jpg / png / webp 等，图片型 PDF 最多 5 页）；粘贴岗位链接智能提取岗位重点
- 后台任务：评估在应用级后台运行，切换页面不中断、可多任务并行，右下角悬浮任务栏可查看

### 简历功能
- 生成简历：填内容 → 实时预览（A4 等比缩放）→ 导出 → 一键去评估
- 视觉模板：6 套 —— 单栏经典 / 左右分栏 / 简洁单栏 / 时间轴 / 黑色极简线条 / 蓝色左右分栏
- 内容顺序：经典简约 / 项目优先 / 应届生推荐（结构化模板固定章节顺序）
- 证件照：插入本地图片（≤2MB，仅接受 `data:image/*`）
- 多版本管理：按岗位保存 / 载入 / 删除（最多 20 个），草稿自动保存
- 导出简历：PDF / Word / TXT / Markdown
- 结构化简历：前后端共用 Schema，写严读宽、未知字段丢弃

### 求职辅助功能
- 多岗位对比：一份简历同时对比 2–4 个岗位，按评分排序给出匹配度与结论
- 模拟面试：面试概览、1 分钟自我介绍、专业 / 技术题、项目深挖题、行为面试题、反问环节、面试前提醒
- 岗位方向推荐：根据简历推荐 3–5 个岗位方向（为什么适合 + 需补强 + 关键词）+ 求职建议

### 历史与分享
- 历史记录：按「同一个人」分组，同一人最多保留 30 条（收藏与最高分不清理），展示改进轨迹（较上次 ±N 分）
- 下载历史：回看最近 100 条导出记录（报告 / 简历）
- 分享报告：生成只读链接并带水印；可隐藏联系方式、隐藏姓名（首字 + **）、选择是否附带简历原文；默认 30 天过期、搜索引擎 noindex

### 额度与套餐
- 每日额度：免费档 100 次 / 天，PRO 500 次 / 天；高级模型与 OCR 单独计数；管理员不受限、不计数
- 先扣后退：评估失败自动退还额度，不出现「评估失败了，次数却少了」
- 额度预警：用量 ≥80% 时顶部提示并引导升级
- 升级 PRO：¥9.9 / 月，收款码或外链支付 → 提交申请（含付款邮箱）→ 管理员批准即开通；按月有效期，过期自动降级为免费档
- 多模型：内置 DeepSeek 与智谱 GLM，按提供商分组选择并记忆；免费档默认走免费的 GLM-Flash

### 岗位关键词库（数据资产）
- 关键词沉淀：评估时按 JD 抽取关键词并落库（带岗位名、命中次数）
- 聚合归类：按岗位大类归类 + 泛词清洗，输出高频关键词
- 公开检索：`/keywords` 与 `/keywords/:slug` 服务端渲染 SEO 页，附「基于 N 份真实 JD」社会证明
- 冷启动保护：分类与全站未达门槛时 `noindex` 且不进 sitemap

### 管理功能
- 用户管理：查看用户、当日用量、累计评估数；手动切换套餐（free / pro，未过期 PRO 顺延）
- PRO 开通申请：审批（批准即开通）、查看付款邮箱、超 24 小时未处理告警
- 转化漏斗：游客试用 → 试用后注册转化率，以及注册 / 首次评估 / 追问 / 下载 / 7 日回访计数
- 报告解析健康度：近 N 天解析降级率（样本 ≥200 且降级率 >5% 才启用机器可读块方案）
- 游客转化实验：按 IP 稳定分桶的 A/B（试用次数 / 预览长度）
- 免费额度校准：按用量分布给出建议额度
- 成本看板：按功能 / 模型 / 用户聚合 token 与估算成本
- 反馈与投票：查看结果页「这份报告有帮助吗」投票与文字反馈

### 前端页面
- 首页：简历评估录入（粘贴 / 上传 / 链接抓取 / 模型选择 / 应届生开关 / 试用示例）
- 评估结果页：报告 + 客观分 + 匹配对照 + 追问 + 编辑重评 + 下载 + 分享
- 任务进度页：后台任务实时进度
- 简历模板页（需要登录）：填写 → 实时预览 → 多版本 → 导出
- 多岗位对比页（需要登录）：一份简历对比多个岗位
- 模拟面试页（需要登录）：生成面试准备并下载
- 岗位推荐页（需要登录）：推荐适合投递的岗位方向
- 历史记录 / 个人中心（需要登录）：按人分组的评估记录、下载记录、账号与隐私
- 升级 PRO 页（需要登录）：套餐对比、支付、提交开通申请
- 管理员后台（需要登录 + 管理员）：用户、申请、漏斗、成本、反馈
- 登录 / 注册页：落地页 + 登录注册 + 游客免注册试用
- 分享页：免登录只读报告（带水印）
- 隐私政策页：免登录
- 岗位关键词库页：免登录，服务端渲染（含 `robots.txt` / `sitemap.xml`）
