## 全局约束（每个任务都必须遵守）

1. **测试不许倒退**：每完成一个任务，`npm test` 全绿（当前基线 103 个单测 / 19 文件），
   `npm run acceptance` 17/17 通过。新增逻辑必须带新增单测。
2. **提交规范**：一个任务一个 commit，message 用中文一行式，风格对齐仓库历史
   （如 `额度计费统一：withQuota 唯一入口 + 失败自动退还（堵住 4 处不一致）`）。
3. **不要动的东西**：
   - 游客路径（`server/routes/guest.js`）的独立额度系统（guest_trials 表）保持原样，不在本次收拢范围。
   - `docs/adr/` 已有决策不要推翻；若 01 的"成功后计费"策略需要记录，新增 ADR-0008，不要修改 ADR-0007。
   - 现有 API 请求/响应格式不破坏（前端 `src/lib/api.ts` 依赖现有字段）。
4. **代码风格**：对齐现有代码——中文注释解释"为什么"、ESM import、better-sqlite3 同步 API。
5. **遇到文档与实际代码不符**：以实际代码为准，并在任务完成说明中指出差异。
